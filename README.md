BV MARKETPLACE — GitHub Pages upload guide
==========================================

File: index.html (poori app, single file — no build needed)

GitHub pe free upload steps:
1. github.com pe account banao (already hai to skip)
2. "New repository" — naam: bv-marketplace (Public rakho)
3. "uploading an existing file" link pe click karo
4. index.html aur README.txt dono drag-drop karo
5. "Commit changes" dabao
6. Settings -> Pages -> Source: "Deploy from branch", Branch: main, Folder: / (root) -> Save
7. 1-2 minute wait karo
8. Site live: https://TUMHARA-USERNAME.github.io/bv-marketplace/

Notes:
- Google real sign-in enable karne ke liye: console.cloud.google.com -> OAuth Client ID
  (Web application, Authorized origin = tumhara github.io link) -> file mein GOOGLE_CLIENT_ID = ''
  mein ID paste karo, commit karo.
- Data browser ke localStorage mein rehta hai (har phone/alag browser pe apna data).
- Sabse pehle test karo: Create Your Shop -> Sell a Product.
